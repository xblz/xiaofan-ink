## 配图规则 (跟公众号解耦)

- **图片比例**: 1:1 (1080x1080), 默认
- **张数**: **不固定, 由主题决定** (跟公众号"配图张数不固定" 铁律一致)
  - 1-3 张: 极简 (单图/3 张卡片, 适合短话题/概念简单)
  - 4-6 张: 中等 (经典结构: 封面 + 引入 + 转折 + 图解 + 扎心 + 可选 CTA)
  - 7-9 张: 完整 (适合多步骤解释/案例对比/概念拆解)
  - 默认 4-6 张, 按主题增减
- **风格**: xiaofan-ink 风格 (白底手绘/线条) + 心理学元素
  - **v2.8.7 修正 (8/25)**: 抖音图文配图**对齐 fork 之前 Ian 风格 + 我们 warm-ink 4 色调色板**
    - **纯白底** (无任何"撕下边/米色草稿纸/锯齿边/装订孔/阴影/渐变" 装饰 — 全砍)
    - **warm-ink 4 色都用**: 墨 (#1A1A1A, 主体线稿/小凡) + 红 (#C0392B, 重点批注/问题/结果) + 橙 (#E67E22, 路径/箭头/动作/动态) + 蓝 (#2C5F8D, 补充说明/系统状态)
    - **中文手写为主**, 行业符号保留, 不出现英文
    - **图解型构图**: 1 个核心动作/物体 + 周围手写批注 + 红色高亮关键词 + 蓝色补充注解 + 橙色路径/箭头, 跟 Ian 的 8 张 fork 之前示例图同源 (信息井/一鱼多吃/想法压机/发酵罐/吊桥 那种"装置 + 批注" 风格)
    - **大量留白** (主体只占 40-60%, 留白是设计的一部分)
    - **每张配图承载 1 段完整文案** (1-2 句, 跟公众号 020/021 配图同源)
    - **红色 brush stroke 圈重点字/数字** (不是装饰飘着, 跟 Ian 用 brush 当高亮一致)
  - **v2.8.6 错误链 (留作反例)**: 改纯白底没文字 → 改回撕下草稿纸 → 再次改回纯白底带文字 → **v2.8.7 砍掉所有装饰** (跟 Ian fork 之前 README 视觉铁律一致: 纯白, 不要纸纹/米色/阴影/渐变)
  - **IP 人物** (v2.8.7 修正): **不每张都画 IP**, 根据场景:
    - "你" 的第一人称视角 → 只画手/手指/通用小人 (stick figure), 不用小凡
    - 抽象"你" 的状态 (分类/循环) → 通用小人 (stick figure)
    - 具体动作主体 (秒回/看屏幕/坐工位) → 用小凡 IP
- **新流程前置**: 写每篇之前先列"配图说明表" (在 content.md 末尾), 标每张图的内容/风格/作用
- **抖音配图全状态** (不画人物动作), 跟公众号"动作型→IP" 规则解耦
- **每张配图配 1 个心理学插画元素** (v2.7.2 起, 不只是文字, 还要有 1 个概念图: 天平/账本/箭头/对话气泡/小剪影/问号)
- **插画元素不重复 (v2.8.2 起)**: 每篇插画元素跟历史篇 0 重复, 查"插画元素池"段

## 文案规则 (待写入 style-guide §7)

1. **≤ 300 字** (抖音图文限制)
2. **1 句扎心结尾** (引用块)
3. **心理学概念 → 1-2 个生活场景 → 1 句扎心** 三段式结构
4. **不主动亮心理咨询师证书** (让内容自己说话)
5. **不鸡汤不卖萌不喊口号** (跟公众号"死板冷静" 调性同源)
6. **话题标签**: 3-5 个, 心理学相关

## content.md 模板 (每篇复用)

1. **front matter** (n/title/platform/date/cover/images/tags)
2. **抖音正文** (300 字内, 复制粘贴用)
3. **抖音上传指南** (步骤: 上传图片 → 填标题 → 粘贴正文 → 加话题标签 → 发布)
4. **话题标签** (复制粘贴)
5. **配图说明** (表格: 文件/内容/风格/作用)
