# 抖音内容源

> 抖音"观心微语" 账号的内容源, 跟公众号 `doc/essays/` 完全独立, 共享 IP 形象 + 风格规范。

---

## 文件命名

`NNN-<slug>.md` (跟公众号 essays 同结构, NNN 从 001 开始, 3 位补零)

## front matter 规范

```yaml
---
n: "001"             # 编号
title: "..."          # 标题 (≤ 30 字)
platform: douyin      # 固定 douyin
date: 2026-08-19
images:               # 1-9 张, 1:1 (1080x1080)
  - 00-cover.png
  - 01-explain.png
  - 02-punchline.png
cover: 00-cover.png   # 抖音图文第一张就是封面
---
```

## 配图规则 (跟公众号解耦)

- **图片比例**: 1:1 (1080x1080), 默认; 也可 3:4 (1080x1440) 留白多
- **张数**: 1-9 张, 3 张经典 (封面 + 解释 + 扎心), 1 张单图也常见
- **风格**: xiaofan-ink 风格 (白底手绘/撕下草稿纸/线条) + 心理学元素
- **新流程前置**: 写每篇之前先列"配图场景表", 标动作/状态 (抖音**全状态**, 跟公众号"动作型→IP" 解耦)

## 文案规则 (待写入 style-guide §7)

1. **≤ 300 字** (抖音图文限制)
2. **1 句扎心结尾** (引用块)
3. **心理学概念 → 1-2 个生活场景 → 1 句扎心** 三段式结构
4. **不主动亮心理咨询师证书** (让内容自己说话)
5. **不鸡汤不卖萌不喊口号** (跟公众号"死板冷静" 调性同源)
6. **话题标签**: 3-5 个, 心理学相关 (#讨好型人格 #心理学 #心理疗愈 #原生家庭 #边界感)
