# 抖音正文 (≤ 300 字)

我删过 1 条朋友圈, 删前想了 18 分钟。

不是图片, 不是视频, 是 23 个字: "今天回家, 看见爸妈, 他们老了一点。"

写完, 1 个赞, 0 条评论。 1 个赞是我自己点的 (测试), 0 个赞是 18 分钟后 (取消测试)。

18 分钟, 23 个字, 0 个赞。

我没删字。 我删的是"被看见的可能"。

朋友圈不是"分享", 朋友圈是"决定被谁看见"。

你删过 1 条朋友圈吗。 你删的, 是字, 还是"被看见的可能"。

> 18 分钟 / 1 条 / 0 赞 — 删不是决定, 删是"决定被谁看见"。
