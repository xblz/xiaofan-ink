# 抖音正文 (≤ 300 字)

你屏蔽了 23 个人的朋友圈。
19 个是同事。
4 个是亲戚。
0 个是朋友。

你以为你在"屏蔽人"。
你只是在"分类"。

5 月屏蔽了前同事 A, 因为他每天发"加班到 11 点"。
7 月屏蔽了高中同学 B, 因为他晒孩子晒到第 200 张。
上周屏蔽了亲戚 C, 因为他每天转发养生谣言 17 条。

每一个屏蔽都有"理由"。
每一个理由都是"我受不了"。

你删完了 23 个人, 朋友圈还剩 47 个能看的人。
但你刷朋友圈的次数, 从每天 23 次降到 4 次。

你以为你在躲人。
你只是在"养" 那个不刷朋友圈的版本。

后来你想加回那个前同事 A。
你点进他头像, 看到"已屏蔽"。
你犹豫了 3 秒, 没动。

23 个被屏蔽的人, 0 个是朋友。
47 个还能看的人, 你也想屏蔽 11 个。

你的朋友圈, 不是"在" 朋友那里。
是"在" 你想成为的那个人那里。

> 屏蔽 23 个人的朋友圈, 0 个是朋友 — 你以为你在躲人, 你只是在分类。
