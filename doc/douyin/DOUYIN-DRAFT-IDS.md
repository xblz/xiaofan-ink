### 三条规则修正

**① 空间叙事 > 人物并置** (043 vs 041 对照)

043 和 041 同批创作、同 6 张 3 IP、切口都是"普世直接观察",唯一实质差别:
- 043 = **空间等不来** (电梯坏了 → 走楼梯 → 一整天记着), 1.2 万
- 041 = **人物并排等** (4 个人低头看手机 → 5 分钟没人动), 746

电梯有"物理上无法绕过"的强制性, 不需要代入感就能看懂。"4 个人低头看手机"要读者先认同状态才能共情, 门槛高一档。

**② 场景公共性 > IP 密度** (推翻 v2.8.34 的 8 要素优先级)

037/038 首日数据出来了, **两篇都跑不动**:
- 037 客厅沙发: 185 播放, 划走 43.96%
- 038 厨房热牛奶: 98 播放, 划走 47.87%

两篇都完整执行了 v2.8.34 跑赢模式 8 要素 (6 张 / 3 IP 50% / 私人空间 / 去"周X" / 姿态动态化), **全部失效**。

原因: 场景是"私人空间 + 自我投射" —— 只有你自己才会经历的独处时刻。对照 043 的电梯是公共的、被迫的、人人都遇到。

**8 要素里的"3 IP 50% 密度"和"去周X"是形式项, 盖不住"场景是不是公共的"这个决定项。**

**③ 留存指标 ≠ 破圈能力** (043 vs 044 对照)

| | 043 | 044 |
|---|---:|---:|
| 划走率 | 28.54% | 29.31% (几乎一样) |
| 展开率 | 6.73% | **12.31%** (全站最高) |
| 播放 | **1.2 万** | 288 (差 40 倍) |

044 留存指标全优却跑不动。差别在**有没有传播理由**:
- 043 讲的是**一件外部发生的事** → 别人会转发"我们小区也这样"
- 044 讲的是**我每天重复的动作** → 只能靠认同, 没有转发理由

评论和转发都来自"我也遇到过", 不是"我懂这个感受"。
