# 抖音正文 (≤ 300 字)

周三下午 1 点。

手机上跳出一条短信。

我的快递被退回了。

理由那一栏写着 3 个字:

地址不全。

我站在原地看了大概 10 秒。

地址不全。

那是我自己填的地址。

下楼去驿站拿。驿站的人翻出退件单,指着一行小字:

第 4 段,空格。

我填的时候少打了一个数字。

就一个数字。

东西在外面走了 3 天。

回来的时候,理由是我写错了一个数字。

我等了 3 天。

它用 1 条短信告诉我:

你填错了。
