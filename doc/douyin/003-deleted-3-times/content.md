# 你删了那个人 3 次, 又加回来 3 次, 第 4 次终于没再加, 但你刷了 8 次他朋友圈

## 抖音正文 (300 字内, 复制粘贴用)

你删了那个人 3 次。
又加回来 3 次。
第 4 次你终于没再加。
但你刷了 8 次他的朋友圈。

你以为你"放下了"。
你只是"不让他看见你"。

你换了头像,
改了签名,
设了仅 3 天可见。
你在他看不见的地方,
调整了 8 次你的朋友圈。

你不是想他。
你是不想让他以为你还在想他。

> 删掉一个人, 容易。
> 删掉"他以为你还在想他" 的可能, 难。
