# 抖音正文 (≤ 300 字)

你"算了"说了 365 次。
1 次都没坚持。

你以为"算了"是随和。
"算了"是没边界。

第 1 次: 同事抢会议室, 你本来想说话, 出口变成"算了, 你先用"。
第 2 次: 外卖小哥送错餐, 你本来想退货, 出口"算了, 将就吃"。
第 3 次: 朋友说错话伤到你, 你本来想表达, 出口"算了, 没事"。
第 4-365 次: 同样的剧本, 想坚持 → 算了。

365 次"算了", 0 次"我想要"。

你以为你"随和"。
其实你连"我想要"都没说出口过。

每次想说"我想要", 出口就变成"算了吧"。
不是因为你不想, 是因为你不知道怎么说。
不是因为你大度, 是因为你怕拒绝。
不是因为你随便, 是因为你不知道"随便"最后变成"随便"。

后来我学会 1 件事: 把"算了"换成"我想要"。
"算了, 你先用" → "我下个会议要用会议室"
"算了, 将就吃" → "麻烦给我换一份"
"算了, 没事" → "你刚才说的, 让我有点不舒服"

不是计较, 是边界。
不是不随和, 是不消失。

你今天说过几次"算了"?
是不想, 还是不敢?

> 365 次 / 0 次坚持 — 你以为"算了"是随和, "算了"是没边界。 把"算了"换成"我想要", 你就回来了。
