# 抖音正文 (≤ 300 字)

你点赞 32 个朋友圈。
私聊 0 个。

你以为赞是"关系"。
赞只是"点赞"。

我刚刷完朋友圈, 32 个赞, 6 分钟。
点完, 退出来, 微信对话列表最新一条是 3 个月前。

第 1 个赞: 同事出游照。
第 2 个赞: 前同事的咖啡。
第 3 个赞: 大学同学的新车。
第 4-32 个赞: 我也不记得谁了, 滑动时手自动点的。

我打开 32 个对话框, 都没点。
不是没话说, 是不知道说什么。
"在吗" "你好" "好久不见" — 3 个月前我都没说出口。

32 个赞花 6 分钟。
0 条私聊花 0 分钟。
但 32 个赞, 让我觉得"我跟 32 个人还有联系"。
0 条私聊, 让我知道 — 我跟 32 个人, 其实没有。

强关系不需要赞。
需要私聊。
但私聊, 比点赞累 100 倍。

你上次私聊, 是给谁? 多久了?

> 32 赞 / 0 私聊 — 你以为赞是关系, 赞只是点赞。 强关系不在朋友圈, 在对话框。
