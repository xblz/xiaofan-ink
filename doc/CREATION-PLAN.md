# xiaofan-ink 长期创作计划

> 这个文档定义**长期创作的节奏、规范、流程和决策机制**。
> 跟 `SERIES-STATE.md` 配合用:本文定"怎么创作",SERIES-STATE 记"已创作什么、待创作什么"。
>
> 任何长期创作的修改(频率调整、风格变化、工具变更)都在本文档更新。

---

## 0. 创作初衷

写这个号最初没想做大。就是把"我从哪些'高效工具'里走出来了"记下来,看看到底是工具不对,还是我不对。

跟"成功学"和"干货文"反着来:这里只谈"我不再做什么"和"我做错了什么"。

**核心三句话**(整个号的灵魂):

1. **过程比结论值钱**
2. **草稿比作品诚实**
3. **死板冷静**

这三条是判断"要不要写一篇 / 写完要不要发"的标准。如果一篇东西写得像"成长博主" / "自律达人" / "干货文",那就删掉重写。

## 2. 节奏与频率

> **v1.7 调整**:不固定更新频率,想写就写。原"每周三 1 篇"已废弃。
> 调整原因:固定时间 → 又走回"每日计划"老路 → 写不出硬憋 → 出水文。
> 跟系列调性"过程 > 结论 / 草稿 > 作品"自洽。

| 维度 | 规则 | 备注 |
|------|------|------|
| **更新频率** | **不固定,想写就写** | 一周 2 篇也行,一个月 1 篇也行 |
| **发布日** | **不固定** | 写完就发,不为时间服务 |
| **创作时间** | 30-60 分钟/篇 | 写作 + 出图 + QA 全包含 |
| **跳过机制** | 没灵感就不写 | 不强行出烂文,不立 flag |
| **预告机制** | **不预告** | 不发"下周三见" 类承诺 |
| **追更机制** | **不催更** | 读者视角别有期待(没期待就不会失望) |

### 为什么"不固定"而不是"每周 1 篇"

- 固定频率是另一种"管理自己"工具,跟"5 年每日计划" 反思的"我不再做"立场矛盾
- 反思文需要"沉淀时间",周更逼出来的东西容易像"打卡文"
- 实战 1-3 验证过:4 张图一次过的稳定性,但前提是"想清楚再写"
- 节奏松散反而让"过程比结论值钱"立得住

### 灵感触发 vs 强写

- **有灵感时**:立刻写,趁热
- **没灵感时**:去看书 / 看代码 / 看生活,不写
- **催稿时**(用户/读者):如果 1 个月内没新文,自动暂停"等触发"信号,不发"下周三见"

## 3. 内容结构(每篇)

### 3.1 文章结构

```
[标题] — 12 字以内,跟主题呼应,允许 1-2 句
[引子段] 1 段 — 触发场景,生活化开头
[主段 1-3] 3 段 — 每段一个核心判断
[收束] 1 段 — 冷幽默 / 反共识 / 留个问号
```

### 3.2 配图结构(不固定张数)

每张图对应文章里 1 个"认知锚点":
- **3 张图** = 短文章(3 锚点 + 收束)
- **4 张图** = 标准长度(默认)
- **5-6 张图** = 长文/角度多时
- 原则:**有 1 个锚点就 1 张图,不为了凑数加图,也不为了"标准 4 张"硬减**

### 3.3 视觉规范(三维度轮换)

**表情**:
- 同文 1-2 张用默认 deadpan
- 1-2 张用微表情(从 5 个里选)
- 同文不超 3 种不同表情
- 情绪节奏建议:平 → X → Y → 平(完整呼吸)

**装扮**:
- 1-2 张用备选装扮(从 6 个里选)
- 2-3 张不用,避免"全用/全不用"两个极端
- 装扮跟"段落主题"要契合,不是装饰

**姿态**:
- 5 张图里至少 4 种不同
- 5 种主姿态:站 / 蹲 / 卡 / 探 / 坐,轮换避免连续两篇同姿势
- 加分项:回头看画外 / 单手托下巴 / 被绊住 / 半个身子卡住(实战 1-3 没用过)

### 3.4 物件池(防反复刻)

**已用**(实战 1-3 + 实战 1/2/3 用过的):
- 文档 / 白板 / 天平 / GTD 机器 / 清单山 / 3 张纸 / 坏机器 / 废稿山 / 3 个开头 / 折弯箭头 / 废稿堆

**未用**(可从下面选,或发明新的):
- 门 / 钥匙 / 锁 / 井 / 梯子 / 船 / 桥 / 邮筒 / 信
- 桌子 / 椅子 / 书架 / 瓶子 / 罐子 / 抽屉 / 柜子
- 绳子 / 链条 / 墙 / 窗 / 影子 / 镜子
- 纸箱(实战 1-3 没用过 ip-reference 里出现过)/ 灯笼 / 风筝

详见 `SERIES-STATE.md` 维护。

## 4. 创作流程

### 4.1 触发

**方式 A(用户主动)**:用户说"创作一篇"或"写一篇关于 X 的"
**方式 B(agent 主动)**:agent 自主从"角度池"里选,直接开干,完成后给用户看文档
- 默认 B 模式:用户说"创作一篇"→ agent 自主选主题 + 写文 + 出图 + 入库,最后给用户看
- 用户可以 A 模式指定主题(但默认走 B)

### 4.2 流程(30-60 分钟)

```
[1] 读 xiaofan-ink skill(SKILL.md + 5 个 references,5-10 分钟)
[2] 读 SERIES-STATE.md,知道已写过什么/还能用什么(2 分钟)
[3] 设计本文角度(避开历史,非共识但成立,3-5 分钟)
[4] 写文章正文(15-20 分钟,4-6 段,600-1000 字)
[5] 设计 shot list(4-6 张,3 维度轮换,5 分钟)
[6] 出图(2-3 分钟/张,4-6 张共 10-20 分钟)
[7] QA(看每张图是否过标准,1-2 分钟)
[8] 写实战 prompt 库到 assets/prompts/articles/(5 分钟)
[9] 追加到 SERIES-STATE.md(2 分钟)
[10] 给用户交付:文章 + 图 + 表情/装扮/姿态轮换说明(2 分钟)
```

### 4.3 用户参与

- **审稿**:产出后用户看一遍,有要改的告诉我
- **不参与选主题**:agent 自主决定(用户给触发信号"创作一篇",不指定主题)
- **拍板**:系列名、频率、长度等元决定(只在 v1.2 拍板过,以后不重复问)
- **发布决定**:用户看完文档后决定发布到哪里(目前本地仓库,未来可能接平台)

## 5. 决策与调整

### 5.1 周期 review

- **每 5 篇** review 一次:看 SERIES-STATE,确认没角度重复、轮换正常
- **每 10 篇** 复盘:调性是否一致、视觉是否疲劳、读者反馈(如果有的话)
- **不按"周" 算,按"篇数" 算**(v1.7 调整)

### 5.2 失败信号(暂不公开但保留)

- 连续 2-3 篇角度"很水"或"没新意" → 暂停,等灵感
- 视觉开始疲劳(看腻小凡) → 加新表情/装扮
- 找不到合适物件 → 拓宽物件池(发明新隐喻)

### 5.3 终止条件(暂定)

- 写满 50 篇(约一年) → 自然收尾,做成合集
- 灵感枯竭 1 个月 → 暂停,等触发
- 调性变化(想换方向) → 开新系列,本系列归档

## 8. 长期视角(6-12 个月)

> v1.7 调整:不再按"周" 算节点,改成按"篇数" 算。

- **第 1-3 篇**:试水,验证流程和节奏顺不顺(已上线:000/001/002)
- **第 4-10 篇**:累积 5-8 篇,看角度池消耗速度,做第一次小复盘
- **第 11-20 篇**:做一次大复盘,看调性是否一致、视觉是否疲劳
- **第 21-50 篇**:沉淀系列认知
- **第 50+ 篇 / 1 年后**:考虑收尾 / 开新系列 / 改方向
- **触发条件**(任一):
  - 写满 50 篇 → 自然收尾,做合集
  - 灵感枯竭 1 个月 → 暂停,等触发
  - 调性变化 → 开新系列,本系列归档
