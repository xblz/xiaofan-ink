# xiaofan-ink 长期创作计划

> 这个文档定义**长期创作的节奏、规范、流程和决策机制**。
> 跟 `SERIES-STATE.md` 配合用:本文定"怎么创作",SERIES-STATE 记"已创作什么、待创作什么"。
>
> 任何长期创作的修改(频率调整、风格变化、工具变更)都在本文档更新。

---

## 1. 系列定位

| 维度 | 定 |
|------|----|
| **系列名** | _(待定,候选见下)_ |
| **类型** | 中文个人方法论 / 工具反思 短文系列 |
| **长度** | 600-1000 字/篇(简短但有信息密度) |
| **配图** | 4-6 张/篇(默认 4 张,文章长可加到 5-6 张) |
| **调性** | deadpan 冷静 / 反思 / 冷幽默 / 不卖萌 / 不喊口号 |
| **目标读者** | 中文知识工作者(开发者/产品/设计师/写作者) |
| **差异化** | 跟"成功学"和"干货文"反着来 — 谈"我不再做什么"和"我做错了什么" |

### 系列名候选

- 《小凡墨水周记》 — 跟仓库同名,品牌清晰(稳)
- 《草稿本》 — 跟实战 3 主题呼应,暗示"过程比结论值钱"
- 《我学会不用的东西》 — 角度犀利,吸睛,但调性偏自我
- 《工具反思周记》 — 功能明确,但偏工具反思单一角度
- 《不站着的笔记》 — 跟"小凡非站"姿态呼应,隐喻强

## 2. 节奏与频率

| 维度 | 默认 | 备注 |
|------|------|------|
| **更新频率** | **每周 1 篇** | 节奏稳定优先,不追多 |
| **发布日** | **每周三** | 固定时间,培养读者期待(候选:周三/周四/周日) |
| **创作时间** | 30-60 分钟/篇 | 写作 + 出图 + QA 全包含 |
| **跳过机制** | 连续 2 周没灵感 → 暂停,等触发 | 不强行出烂文 |

### 为什么每周 1 篇而不是 2 篇

- 4-6 张图每次生图成本不低(2-3 分钟/张)
- 中文反思文需要"沉淀时间",强行赶工容易出水文
- 实战 1-3 验证过:4 张图一次过的稳定性,但前提是"想清楚再写"
- 周更够建立"系列感",日更反而稀释

## 3. 内容结构(每篇)

### 3.1 文章结构

```
[标题] — 12 字以内,跟主题呼应,允许 1-2 句
[引子段] 1 段 — 触发场景,生活化开头
[主段 1-3] 3 段 — 每段一个核心判断
[收束] 1 段 — 冷幽默 / 反共识 / 留个问号
```

### 3.2 配图结构

每张图对应文章里 1 个"认知锚点":
- 4 张图 = 4 个锚点(默认)
- 5-6 张图 = 5-6 个锚点(文章长/角度多时)

### 3.3 视觉规范(三维度轮换)

**表情**:
- 同文 1-2 张用默认 deadpan
- 1-2 张用微表情(从 5 个里选)
- 同文不超 3 种不同表情
- 情绪节奏建议:平 → X → Y → 平(完整呼吸)

**装扮**:
- 1-2 张用备选装扮(从 6 个里选)
- 2-3 张不用,避免"全用/全不用"两个极端
- 装扮跟"段落主题"要契合,不是装饰

**姿态**:
- 5 张图里至少 4 种不同
- 5 种主姿态:站 / 蹲 / 卡 / 探 / 坐,轮换避免连续两篇同姿势
- 加分项:回头看画外 / 单手托下巴 / 被绊住 / 半个身子卡住(实战 1-3 没用过)

### 3.4 物件池(防反复刻)

**已用**(实战 1-3 + 实战 1/2/3 用过的):
- 文档 / 白板 / 天平 / GTD 机器 / 清单山 / 3 张纸 / 坏机器 / 废稿山 / 3 个开头 / 折弯箭头 / 废稿堆

**未用**(可从下面选,或发明新的):
- 门 / 钥匙 / 锁 / 井 / 梯子 / 船 / 桥 / 邮筒 / 信
- 桌子 / 椅子 / 书架 / 瓶子 / 罐子 / 抽屉 / 柜子
- 绳子 / 链条 / 墙 / 窗 / 影子 / 镜子
- 纸箱(实战 1-3 没用过 ip-reference 里出现过)/ 灯笼 / 风筝

详见 `SERIES-STATE.md` 维护。

## 4. 创作流程

### 4.1 触发

**方式 A(用户主动)**:用户说"写一篇关于 X 的"
**方式 B(我主动)**:每篇前我从"角度池"里选一个,直接说"我准备写 X,主题是 Y,开干吗?"

### 4.2 流程(30-60 分钟)

```
[1] 读 xiaofan-ink skill(SKILL.md + 5 个 references,5-10 分钟)
[2] 读 SERIES-STATE.md,知道已写过什么/还能用什么(2 分钟)
[3] 设计本文角度(避开历史,非共识但成立,3-5 分钟)
[4] 写文章正文(15-20 分钟,4-6 段,600-1000 字)
[5] 设计 shot list(4-6 张,3 维度轮换,5 分钟)
[6] 出图(2-3 分钟/张,4-6 张共 10-20 分钟)
[7] QA(看每张图是否过标准,1-2 分钟)
[8] 写实战 prompt 库到 assets/prompts/articles/(5 分钟)
[9] 追加到 SERIES-STATE.md(2 分钟)
[10] 给用户交付:文章 + 图 + 表情/装扮/姿态轮换说明(2 分钟)
```

### 4.3 用户参与

- **审稿**:产出后用户看一遍,有要改的告诉我
- **主题候选**:可以从"角度池"里选,或自己提
- **拍板**:系列名、频率、长度等元决定

## 5. 决策与调整

### 5.1 周期 review

- **每 5 篇** review 一次:看 SERIES-STATE,确认没角度重复、轮换正常
- **每 10 篇** 复盘:调性是否一致、视觉是否疲劳、读者反馈(如果有的话)

### 5.2 失败信号(暂不公开但保留)

- 连续 2-3 篇角度"很水"或"没新意" → 暂停,等灵感
- 视觉开始疲劳(看腻小凡) → 加新表情/装扮
- 找不到合适物件 → 拓宽物件池(发明新隐喻)

### 5.3 终止条件(暂定)

- 写满 50 篇(约一年) → 自然收尾,做成合集
- 灵感枯竭 1 个月 → 暂停,等触发
- 调性变化(想换方向) → 开新系列,本系列归档

## 8. 长期视角(6-12 个月)

- **第 1-2 周**:试水 1-2 篇,验证流程和节奏顺不顺
- **第 3-8 周**:稳定周更,累积 5-8 篇,看角度池消耗速度
- **第 9-20 周**:稳定产出 10-15 篇,做第一次复盘
- **第 21-50 周**:持续产出 30-50 篇,沉淀系列认知
- **第 51 周**:收尾 + 做合集(MD/PDF/HTML 任选)
