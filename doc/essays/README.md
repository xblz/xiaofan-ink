# 《小凡墨水周记》

> 这是 xiaofan-ink 的正式发布系列。从 `001-` 开始,每周 1 篇,每周三更新。
>
> 调性:deadpan 冷静 / 反思 / 冷幽默 / 不卖萌 / 不喊口号。
> 长度:600-1000 字 + 4 张手绘配图。
> 关联公众号:**小凡的草稿本**(brand 资源见 `brand/` 目录)

按文件名前 3 位数字顺序读,数字就是创作顺序:

- `001-<slug>.md` — 第 1 篇
- `002-<slug>.md` — 第 2 篇
- ...

每篇配图在 `images/00X-<slug>/` 下,跟文章同号。

## 系列元信息

- **开始日期**:2026-07-17
- **更新频率**:每周 1 篇(每周三)
- **目标读者**:中文知识工作者(开发者/产品/设计师/写作者)
- **视觉 IP**:小凡(基于真人风格化转译的 deadpan 角色)
- **跟实战 1/2/3 的关系**:`doc/whiteboard-vs-doc.md` / `doc/why-i-quit-gtd.md` / `doc/why-i-write-drafts.md` 是 xiaofan-ink skill 的**实战验证样本**,不是本系列。本系列从 001 开始,跟实战样本是两条线。

## 系列规范

- **角度**:中文个人方法论 / 工具反思("为什么我不再用 X" / "X 比 Y 更值钱" / "X 的边界")
- **结构**:开头钩子 + 3 段主内容 + 收束
- **配图视觉规范**:同文 1-2 张默认 deadpan + 1-2 张微表情;1-2 张用备选装扮;5 张里至少 4 种不同姿态
- **防重复**:见 `../SERIES-STATE.md`

详见 `../CREATION-PLAN.md`(长期创作计划)。

## 发布到公众号

每篇写完后,手动或自动同步到公众号"小凡的草稿本":

1. 复制 `00X-<slug>.md` 正文到公众号编辑器
2. 上传 `00X-<slug>/` 配图(注意:公众号对单图 5MB 限制,16:9 2K 图通常 1-2MB,够用)
3. 在"封面"位置上传一张(可选,用配图 1 或 3 当封面)
4. 复制 `style-guide.md` 里的字体/排版/强调规则套用
5. 公众号后台更新"目录"关键词回复(加这一篇)
