# 《小凡墨水周记》

> 这是 xiaofan-ink 的正式发布系列,公众号"小凡的草稿本"的主内容来源。
> 调性:deadpan 冷静 / 反思 / 冷幽默 / **过程 > 结论 / 草稿 > 作品 / 死板冷静**。
> 长度:600-1000 字 + 4 张手绘配图。
> 关联公众号:**小凡的草稿本**(brand 资源见 `brand/` 目录)

按文件名前 3 位数字顺序读,数字就是创作顺序:

- `000-grass-journal-intro.md` — 开篇(品牌定位 + 系列预告)
- `001-<slug>.md` — 第 1 篇
- `002-<slug>.md` — 第 2 篇
- ...

每篇配图在 `images/00X-<slug>/` 下,跟文章同号。

---

## 系列初衷

写这个号最初没想做大。就是把"我从哪些'高效工具'里走出来了"记下来,看看到底是工具不对,还是我不对。

写到第几篇算几篇,不想立 flag 说"我要写满 50 篇"。**过程比结论值钱,草稿比作品诚实** —— 这两句话是整个号的核心。

跟"成功学"和"干货文"反着来:这里只谈"我不再做什么"和"我做错了什么"。不教你"如何高效",只想说"我也做不到,然后呢"。

---

## 节奏

**不固定更新频率,想写就写**。

本来想说每周三 1 篇,后来想想 —— 这不就是另一种"每日计划"吗?定了时间就要为时间服务,写不出也硬憋。最后又走回老路。

所以改成:**有想法就写一篇,可能一周 2 篇,也可能一个月 1 篇**。不预告,不催更,不立 flag。

读者视角也别有期待(没期待就不会失望):看到更新就是赚到,没更新说明我在憋大招或者在摸鱼。

## 发布到公众号

每篇写完后,手动或自动同步到公众号"小凡的草稿本":

1. 复制 `00X-<slug>.md` 正文到公众号编辑器
2. 上传 `00X-<slug>/` 配图(注意:公众号对单图 5MB 限制,16:9 2K 图通常 1-2MB,够用)
3. 在"封面"位置上传一张(可选,用 `cover.png` 当封面)
4. 复制 `style-guide.md` 里的字体/排版/强调规则套用
5. 公众号后台更新"目录"关键词回复(加这一篇)

**自动化版本**:`xiaofan-ink/tools/articles-to-wechat.py` 一键同步 markdown → 草稿箱,见 `xiaofan-ink/tools/README.md`。
