# 《小凡墨水周记》

> 这是 xiaofan-ink 的正式发布系列。从 `001-` 开始,每周 1 篇,每周三更新。
>
> 调性:deadpan 冷静 / 反思 / 冷幽默 / 不卖萌 / 不喊口号。
> 长度:600-1000 字 + 4 张手绘配图。

## 怎么读

按文件名前 3 位数字顺序读,数字就是创作顺序:

- `001-<slug>.md` — 第 1 篇
- `002-<slug>.md` — 第 2 篇
- ...

每篇配图在 `images/00X-<slug>/` 下,跟文章同号。
