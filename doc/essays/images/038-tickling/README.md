### ⚠️ IP 失真根因 (用户反馈: "形象和我们 IP 不是很像")

把 `standard.png` 和首版逐项放大对比, 偏差是**具体的三条, 不是"整体不像"**:

| 特征 | standard.png (正确) | 首版 (错) | 后果 |
|---|---|---|---|
| **眼睛** | 一笔短弧 + 一个点 | 画成完整动漫眼 (眼白 + 瞳孔 + 眼睑线) | ❌ 最致命 |
| **眉毛** | 不画, 或极淡短斜线 | 粗黑清晰的两道 | ❌ 脸变严肃 |
| **脸型** | 偏长椭圆 | 偏圆 | 偏卡通 |
| **颜色** | 只有黑线 | 脸颊/脖子/耳朵粉红填充 | ❌ 破坏线稿质感 |

**根因**: `standard.png` 里那两笔短弧+点, 渲染器理解成"画一双眼睛", 于是套了**日系动漫脸三件套** (眼白+瞳孔+眼睑线+粗眉)。
→ **`Pure line drawing. Do NOT fill...` 这条规则管不住它。必须显式点名禁写五官内部结构。**
