## 主题共鸣分析 (v2.8.34)

- **场景识别度**: 极高 (9/28-9/30 中秋国庆夹缝 3 个工作日, 全国打工人共同经历)
- **蹭热点边界 (v2.8.17)**: 蹭"这 3 天没人能干活" 这个**集体意识转向关键词**, 不蹭具体事件 (不点名公司/不写股票/不写请假攻略)
- **反常识 (冲击反转 vs 翻译反转)**: "我不是摸鱼, 我在演" — 从"偷懒"翻转到"表演", 跟 032 "按的不是按钮是'我想快点'" 同级冲击
- **punchline deadpan 收尾**: "刷手机也是上班" — 不喊口号, 不写鸡汤, 冷幽默收尾
- **IP 2 张姿态完全不同**: 02 坐工位低头看手机 (手机前置, 观众看到脸) / 03 站窗边背对侧身 (剪影感, 观众看到轮廓) — 视觉不撞 031 车钥匙 2 IP (02 手握钥匙特写 / 03 驾驶位看窗外)
- **私人空间 (划走率)**: 工位 + 会议室 = 半私人 (自己的工位/熟悉的会议室), 划走率预期 ≤ 35%
