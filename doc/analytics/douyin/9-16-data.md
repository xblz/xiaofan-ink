## v2.8.26 gstack 抓取重大进展

**之前的失败原因 (v2.8.19 + 9/14 + 9/16 第一次)**:
- `cookie-import /tmp/douyin-cookies-final.json` (从 macOS Chrome DB 解密) → 抖音风控拒 (fingerprint 不匹配 OR session stale)
- `cookie-import-browser chrome --domain creator.douyin.com` → 只 13 cookies, 不够
- 9/16 第一次 navigate → 跳登录 (142 cookies 但 reload 触发新验证)

**v2.8.26 成功方法 (刚刚)**:
1. gstack set UA "Chrome/130.0.0.0" + sec-ch-ua headers (跟 9/7 9:44 一致)
2. gstack `cookie-import-browser chrome` (no args, picker UI) → **用户手动在 http://127.0.0.1:24801/cookie-picker 选全部 douyin-related domain** → **142 cookies, 13 domain**
3. **不 reload**, 直接 navigate content/manage → **登录成功, 看到内容管理界面**
4. **第 2 次 navigate** → **跳登录** (抖音风控 per-navigation 新验证)

**v2.8.26 沉淀 (新)**:
- `cookie-import-browser chrome` (no args, picker UI) 是关键, 用户**手动配合 1 次** 即可
- 每次 picker 配合后**只能 navigate 1 次**, 不能 reload 不能 navigate 第二次
- 抓数据最佳流程: picker 配合 → navigate content/manage → 立刻 text/js 抓所有 DOM → 退出 (不要第二次 navigate)
- **用户配合代价**: 1 次 picker UI 选 domain (5-10 秒), 比重启 Chrome + --remote-debugging-port 轻量 100 倍
