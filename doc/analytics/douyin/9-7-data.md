## gstack 抓取经验沉淀 (v2.8.16 新)

### 问题
- 第一次抓 (9/7 上午 8 点) cookie-import-browser 踢出用户 Chrome 登录态 (抖音/微信/支付宝单点登录)
- 默认 UA 含 `HeadlessChrome/145.0.7632.6` ← 风控一眼识别

### 解决方案 (第二次抓成功, 9/7 9:44)
- UA 改成 `Chrome/130.0.0.0` (去掉 HeadlessChrome 标识)
- 加 sec-ch-ua, sec-ch-ua-mobile, sec-ch-ua-platform, Accept-Language headers
- 流程: douyin.com 主页 → cookie-import-browser → creator.douyin.com

### 风险规则 (v2.8.16 沉淀)
- **单点登录平台 (抖音/微信/支付宝) 禁用 cookie-import-browser 直接模式**
- 必须 UA 优化 (去掉 HeadlessChrome) 或改用截图/复制/CDP 模式
- 公众号 (微信扫码登录) 同样风险, 后续 v2.8.17 抓公众号数据时同样处理

### gstack 数据抓取后续 (v2.8.19 沉淀)

- **9/11 抓数据失败**: gstack Playwright 实例 fingerprint 跟用户 Chrome 不一致, 抖音风控跳登录
  - 用户 Chrome sessionid 仍然有效 (cookie 提取 OK), 但 gstack 自己的 Playwright 实例被抖音检测为非真实 Chrome
  - cookie-import-browser 返回 0 cookies (gstack 内部启动临时 Chrome 读 cookie, 临时 Chrome 没登录态)
  - 自己 Playwright 注入 cookies 后, 抖音风控检测 fingerprint 不匹配, 跳登录
- **解决方案**: 让用户在他 Chrome 打开创作者中心, 截图发我, 或让我用 gstack 连真实 Chrome (`--remote-debugging-port`)
- **后续抓数据流程**: 用户打开创作者中心 → 我用 gstack 抓 user Chrome (待实现)
- **v2.8.19 沉淀**: gstack 抖音抓数据从"自动"降级为"半自动", 9/11 起必须用户配合
