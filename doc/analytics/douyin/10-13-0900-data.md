## 抓取技术沉淀 (重要)

### gstack 路径彻底失败 (10-13 验证)

```
cookie-import-browser chrome --domain .douyin.com  → 58 cookies ✅
sessionid 有效期到 2026-11-28, 值有效            → Chrome 侧确实登录 ✅
设 UA 141 + accept-language + sec-ch-ua          → 无效 ❌
页面仍返扫码登录页
```

**根因确认**: 抖音有 `sid_guard` cookie 绑设备指纹。gstack 是 Playwright 实例,`navigator.languages` 仍是 en-US、`screen 1280x720`、`hardwareConcurrency 4`,跟真实 Chrome 不一致,风控判定非本人设备 → 强制掉登录。

改 header 没用,因为指纹在 JS 层 (navigator 对象),不在 HTTP 层。

### 内嵌浏览器路径成功 (10-13 验证)

**真实 Chromium (Electron) 指纹能过风控**,但需要用户扫码一次。

**踩坑记录**:
1. `navigate` 对已加载 tab 报 `current_tab_occupied` → 用 `open_tab`
2. FilePanel 视口窄 (640px) 时,内容区塞进 375×667 移动端 iframe,**作品列表接口一个都不发**,页面永远转圈 → 换新 tab 后视口 878×1280 正常
3. 页面有 2 个引导浮层 ("合集管理移到这里啦" / "点这里进入评论管理") 挡住数据,需各点一次「知道了」
4. 滚到底后 `atEnd: true`,虚拟滚动只加载 12 篇

### 结论

**抓取路径定案**: 内嵌浏览器 + 用户扫码,替代 gstack。gstack 路线放弃。

**遗留**: 仍只能抓首屏 12 篇,拿不到 333 篇全量 (333 = 作品总数)。历史数据靠 `doc/analytics/douyin/*.md` 快照积累。
