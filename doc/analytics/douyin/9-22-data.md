### 031「睡前刷手机」跑不动核心 3 个错

1. **主题同质化**: "睡前刷手机反思" 是抖音/小红书的**高竞争流量池**, 算法反复推过, 用户对这类内容**标题脱敏**. 抖音判断这内容 = 已有同质内容, 初始曝光给的少 (展开率 5% 上下, 跟 029 6% 同档, 但初始流量池已经分流).
2. **反常识强度太弱**: "刷≠刷" / "今天/明天" 是**翻译型反转** — 翻译的是"刷手机 = 不想今天结束". 这种翻译需要**主动思考**, 抖音 3 秒划走机制不给思考时间. vs 025 "钥匙 3 次" / 029 "退休≠歇" / 030 "点头=草稿" 都是**冲击反转** (强具象反常识).
3. **punchline 抽象**: "你放不下的不是手机, 是今天" — "今天"抽象, 不如"有事做的人" (029) / "关系草稿" (030) 那种**具象收尾**. 抽象 punchline 不留用户的"二次回看"理由.

**额外**: 02-time-skip 是抽象时间线 (23:00→23:30→0:00), 视觉信息密度低, 跟 029 "起床/遛狗/买菜/接孙/熬粥" 那种**5 动作具象时间线**比不了.

### 032「下雨等雨」跑不动核心 4 个错

1. **展开率 1.41% 极低**: 抖音判断标题/封面**质量分太低**, 初始曝光给的极少 (vs 029 6.08% 4.3x 差距). 可能封面"雨"反复出现触发抖音去重.
2. **场景低频**: "在公司楼下等雨" 是个**相对低频场景** — 很多人要么开车、地铁、叫车回家, 主动在楼下等雨的人少. 抖音 push 给"都市通勤人群"后, 大部分人没共鸣.
3. **反常识太抽象**: "等雨 = 等今天不用做选择" — 这层意思需要用户**主动脑补**, 抖音算法不给慢思考. vs 029 "退休 = 比上班还忙" 是**事实反常识**, 用户一看就懂.
4. **画面"静"而无张力**: 雨天 + 公司楼下 + 1 人剪影 — **画面色调单一** (雨灰色调), 暖色调只有 IP 那张. 抖音算法偏好**多色彩+细节**画面. vs 029 公园+大爷+金毛+公园剪影**多元素构图**.
