## 防重复规则(给 agent 的硬约束)

1. **角度查重**:开始创作前先看"已写过的文章"段,如果新主题跟历史角度 80% 重合,**改用不同切口**(比如"工具反思"已写过,可以改用"工具反思的边界"或"工具的副作用"等次级角度)
2. **三维轮换**:每次创作前查"三维轮换状态跟踪",优先用"未用"池里的元素
3. **同文配比**:
   - 表情:同文 1-2 张 deadpan + 1-2 张微表情
   - 装扮:同文 1-2 张用,2-3 张不用
   - 姿态:5 张图里至少 4 种不同
4. **物件创新**:每篇文章用新物件池(从"未用"列表里选 1-2 个,或发明新的)
5. **结构类型轮换**:8 种结构类型(Workflow / 系统局部 / 前后对比 / 角色状态 / 概念隐喻 / 方法分层 / 地图路线 / 小漫画分镜)尽量分散,不要连续 3 篇都用同一种
