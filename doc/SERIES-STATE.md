### 生活小事角度池规则(给 agent 的硬约束)

1. **真发生过的具体小事**:不是"应该 X, 应该 Y" 的说教, 是"我今天在路口, 30 秒"
2. **反共识的道理**:不是"我学到了 A", 是"我以为 A, 其实是 B"
3. **暗合核心三句话**:每篇落到过程 / 草稿 / 死板冷静 之一
4. **避坑**:
   - ❌ 不要变成"生活随笔文"(会软)
   - ❌ 不要"温暖治愈"调子(会卖萌)
   - ❌ 不要"积极向上"口号(会破调性)
5. **保持**:
   - ✅ 1-2 张配图(应用 v1.8 IP 决策规律)
   - ✅ 1 句冷幽默收尾(引用块)
   - ✅ 短句 + 短段(2-4 行/段)

## 防重复规则(给 agent 的硬约束)

1. **角度查重**:开始创作前先看"已写过的文章"段,如果新主题跟历史角度 80% 重合,**改用不同切口**(比如"工具反思"已写过,可以改用"工具反思的边界"或"工具的副作用"等次级角度)
2. **三维轮换**:每次创作前查"三维轮换状态跟踪",优先用"未用"池里的元素
3. **同文配比**:
   - 表情:同文 1-2 张 deadpan + 1-2 张微表情
   - 装扮:同文 1-2 张用,2-3 张不用
   - 姿态:5 张图里至少 4 种不同
4. **物件创新**:每篇文章用新物件池(从"未用"列表里选 1-2 个,或发明新的)
5. **结构类型轮换**:8 种结构类型(Workflow / 系统局部 / 前后对比 / 角色状态 / 概念隐喻 / 方法分层 / 地图路线 / 小漫画分镜)尽量分散,不要连续 3 篇都用同一种
6. **生活小事角度池**(v2.0 起):见上文"角度池" 段, 候选 7 个, 跟"工具反思" 角度池互不挤占
