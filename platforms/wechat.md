## 内容定位 (跟抖音完全不同)

| 维度 | 公众号 (小凡的草稿本) | 抖音 (观心微语) |
|---|---|---|
| 主题 | 工具反思 / 过程 > 结论 | 心理学 / 情感 / 扎心文案 |
| 调性 | 死板冷静 / 不卖萌 | 死板冷静 / 不卖萌 (同源) |
| 视觉 | 白底小凡 deadpan 草图 | 白底撕下草稿纸+心理学元素 (抖音独立场景) |
| 文案长度 | 1000-1500 字 | 300 字以内 |
| 配图比例 | 16:9, 4 张 (默认, 不固定) | 1:1, 1-9 张 (不固定) |
| 封面 | 订阅号用不上 (无头图) | 1:1 必须, 抓眼 |
| 风格统一项 | 调色板 / 字体 / 留白 / 不喊口号 / 不卖萌 | 同上 |

**核心约束**:
- 公众号写"工具反思", 抖音写"心理学", 两个独立, 主题不交叉
- IP 形象 (小凡) 共享 reference 库, 但具体配图场景走各自调性
- 文案调性共享"不卖萌/不喊口号", 但落点不同 (公众号 = 工具, 抖音 = 心理)

## 公众号创作硬规则 (沉淀到 style-guide §1-§6 + §6.x)

1. **1000-1500 字** (公众号正文长度, 不严格)
2. **过程比结论值钱 / 草稿比作品诚实 / 死板冷静** (核心三句话, 落到场景里, 不喊)
3. **品牌名不直接出现** (珠宝/餐饮/酒水 → 通用描述代替)
4. **不重复历史切口** (查 `doc/SERIES-STATE.md` 防重复)
5. **不重复"动作型/状态型" 配图决策** (查 `doc/SERIES-STATE.md` 三维轮换)
6. **配图张数不固定** (由主题决定, 默认 4 张, ## 段 0-8 张灵活)
7. **## 段内容长度不均** (短 1-2 行 / 中 3-4 行 / 长 5-6 行 交替)
8. **主题词不喊** (不写"我学会了过程 > 结论", 落到场景里)
9. **配图 IP 决策** (v1.8): 动作型画面 → 保留 IP; 状态型画面 → 去 IP
10. **不立 flag, 不催更** (v1.7 节奏)

## 工具链 (公众号创作全流程)

### 1. 内容源: `doc/essays/00X-<slug>.md`

**front matter 规范**:
```yaml
---
n: "017"             # 编号 (3 位补零)
title: "..."          # 标题 (推送标题, 不带《》)
digest: "..."         # 摘要 (≤ 54 字, 优先于 title 截取)
date: 2026-08-17
images:               # 4 张配图, 16:9, 默认
  - 00-price-tag.png
  - 01-looking-at-price.png
  - 02-year-curve.png
  - 03-checking-bill.png
---
```

**正文**: 1000-1500 字, ## 段分割, 段长不均, 短句+短段

**配图引用**: `![alt](images/00X-xxx/NN-xxx.png)` (跟 front matter `images:` 列表**数量一致**, 自检)

### 2. 配图生成: `image_synthesize` 工具

- **IP 形象图**: `xiaofan-ink/assets/ip-reference/standard.png` 作 `input_file_paths`
- **状态图**: 不加 reference, 单独 prompt
- **PIL JPEG 化**: 微信 API 兼容性, ffd8 JPEG 数据 + .png 后缀

### 3. 同步前自检 (必跑)

- img 引用数 (`![]()` 数量) = front matter `images:` 列表数
- 每张配图 prompt 含 "Chinese only" 关键词
- 6-9 月的 IP 形象图 prompt 含 "short-sleeve t-shirt" + "Hangzhou summer"

### 4. 敏感词检查: `xiaofan-ink/tools/sensitive-check.py`

- 4 类检查: 品牌名 (珠宝/餐饮/酒水) / 违规引导 (扫码/加微信) / 医疗夸大 / 金融夸大
- 集成到 `articles-to-wechat.py` 步骤 1.5
- 默认 warn-only 不阻断, 加 `--strict` 阻断

### 5. 同步草稿: `xiaofan-ink/tools/articles-to-wechat.py`

```bash
# 同步 1 篇
python xiaofan-ink/tools/articles-to-wechat.py 017

# 列所有 essays
python xiaofan-ink/tools/articles-to-wechat.py --list

# 测试 API
python xiaofan-ink/tools/articles-to-wechat.py --test
```

**输出**:
- 配图 4 张上传到图文消息内图片 API
- 封面用 `00-*.png` 作 `thumb_media_id`
- 草稿创建成功 → 草稿 ID
- 草稿 ID 记到 `doc/SERIES-DRAFT-IDS.md`

### 6. 草稿箱清理 (用户手动, 微信 API 不支持删)

- 多次同步会留多版本, 用户去公众号后台草稿箱手动删
- `doc/SERIES-DRAFT-IDS.md` 草稿箱段只保留最新 ID

### 7. 群发 (用户手动)

- 公众号后台草稿箱 → 选草稿 → 群发/定时发布
- 群发后草稿 ID 失效, `doc/SERIES-DRAFT-IDS.md` 已发段不保留 ID
