- 文案调性共享"不卖萌/不喊口号", 但落点不同 (公众号 = 工具, 抖音 = 心理)

## 公众号创作硬规则 (v2.8.20 数据反推版重写)

> **完整版在 `xiaofan-ink/references/wechat-writing-rules.md`** —— 全部带 29 篇实算中位数, 写之前必读。
> 下面是速查。

### 写作规则 (决定能不能跑)

1. **选题起点必须在读者身上** — 一个"人人做过的小动作", 不是"最近发生了什么"。自检三字「读者做过吗」, 答不上来就换题。**这条的价值大于其他所有条加起来。**
2. **标题**: 必须含「我」+ 一个具体动作 + 时长/次数, **≤18 字**, **不写判断句** (禁用「不是…是…」「其实是」)。判断句标题中位 **31**, 非判断句 **122** —— 差 4 倍。
3. **不要为了加数字硬塞数字** — 含数字组中位 108, 不含数字 128, 加数字没有优势。数字只有是动作的一部分时才有用。
4. **正文 600-800 汉字, 900 字是硬上限** — 字数与阅读是单调负相关 (<700 中位 136 / >1100 中位 36)。不是"700-900 最优", 是**越短越好**, 但别为了凑短把动作写弱。
5. **埋 1-2 个「可划线句」** — 单独成行 + 加粗 + 前后不跟解释。全站 7,035 阅读划线 **0** 次, 读者想划但没东西可划。
6. **结尾引用块金句** — 有引用块中位 **130**, 无 **48**, 接近 3 倍差距, 不要省。
7. **引用块后加 1 句互动钩子** — 对照型 / 邀约型 / 转发理由型。**禁用"点赞在看转发"**, 违背调性且效果差。
8. **绕开**: 政策 / 财经 / 品牌名 / 工作倦怠 / 行业宏观数字 / 纯私人身体体验。前两类还有限流风险。

### 沿用旧规则 (未被数据推翻)

9. **死板冷静 / 不卖萌 / 不喊口号** (核心三句话: 过程比结论值钱 / 草稿比作品诚实 / 死板冷静, 落到场景里, 不喊)
10. **品牌名不直接出现** (珠宝/餐饮/酒水 → 通用描述代替)
11. **不重复历史切口** (查 `doc/SERIES-STATE.md` 防重复)
12. **主题词不喊** (不写"我学会了过程 > 结论", 落到场景里)
13. **## 段内容长度不均** (短 1-2 行 / 中 3-4 行 / 长 5-6 行交替)
14. **配图 5 张 16:9** (不因"看起来 5 张跑不动"就改 —— 破千的 1006 和 526 本身就是 5 张, 且 9 月后全 5 张无同期对照, 无法归因)
15. **IP 至少 1 张** (v2.8.18 防失联硬规则, 破防红线: 连续 3 篇 0 IP = 失联)
16. **不立 flag, 不催更** (v1.7 节奏)

### 发布规则 (v2.8.20)

17. **一次只发一篇** — 两次多图文群发, 后位文章只有头篇的 **5%-17%** (08-25: 334/18/23; 09-10: 181/31)
18. **原创 + 贴图双发** — 贴图不占群发通知次数, 累计 788 阅读 (占 11%), 白捡。
    ⚠️ **但不要当"原创权重加成"** — 全部配对中位只有 1.22×, 且三个变量同时不同, 不是受控对比。双发是因为没成本, 不是因为有加成。

## 工具链 (公众号创作全流程)

### 1. 内容源: `doc/essays/00X-<slug>.md`

**front matter 规范**:
```yaml
---
n: "017"             # 编号 (3 位补零)
title: "..."          # 标题 (推送标题, 不带《》)
digest: "..."         # 摘要 (≤ 54 字, 优先于 title 截取)
date: 2026-08-17
images:               # 5 张配图, 16:9 (v2.8.20 固定 5 张)
  - 00-cover.png
  - 01-first.png
  - 02-grid.png
  - 03-delete.png
  - 04-punchline.png
---
```

**正文**: 600-800 汉字 (900 硬上限), 5 个 `##` 段分割, 段长不均, 短句+短段
**必须包含**: 1-2 个可划线句 (单独成行 + 加粗) + 结尾引用块金句 + 引用块后 1 句互动钩子

**配图引用**: `![alt](images/00X-xxx/NN-xxx.png)` (跟 front matter `images:` 列表**数量一致**, 自检)

### 2. 配图生成: `image_synthesize` 工具

- **IP 形象图**: `xiaofan-ink/assets/ip-reference/standard.png` 作 `input_file_paths`
  - ⚠️ **只传 reference 不够** —— 必须同时写死 IP 形态段 (刘海/淡短眉/细长眼/偏长脸/有指节的手), 见 `xiaofan-ink/assets/prompts/_standard-ip-description.md` v2.8.43 段
  - ⛔ **刘海绝对不能后梳 / 不能露额头** (v2.8.42 事故: 禁眉毛 → 逼出后梳 → IP 核心特征被抹掉)
- **状态图**: 不加 reference, 单独 prompt
- **PIL JPEG 化**: 微信 API 兼容性, ffd8 JPEG 数据 + .png 后缀
- **公众号专用模板**: `xiaofan-ink/references/prompt-template.md` 模板 A (16:9, 人物在场景里, 主体 50-65%)
  - ⛔ **不要用抖音的"大留白/40-60%"** —— 那是抖音适配层, 公众号用了会退回空壳符号型 (039 反模式)

### 3. 同步前自检 (必跑)

- **跑 `python3 xiaofan-ink/tools/ip-preflight.py check-essay <编号>`** → 校验 img 引用数 / 文件存在 / basename 顺序 / ffd8 JPEG / 1376×768, 有阻断项不许同步
- **跑 `python3 xiaofan-ink/tools/ip-preflight.py check-prompt <prompt文件>`** (生图前) → 校验刘海约束 / 禁填充正向段 / 眉眼正向描述 / 危险词
- img 引用数 (`![]()` 数量) = front matter `images:` 列表数 = 5
- 每张配图 prompt 含 "Chinese only" 关键词
- prompt 不写 hex 色号, 用颜色名 + 加 "do NOT write any color codes, hex codes, hash symbols" (v2.8.34 预防规则)
- **5 张图必须逐张视觉验收**: API 返回成功 ≠ 画面正确 (10/04 039 封面画成了 034 内容, 02 的"了"字渲染成"弓")
- **含 IP 的图必须裁切放大看脸** (`ip-preflight.py crop-face <图>`): 整图验收 100% 漏眉毛
  - 查 3 条: 刘海在不在 / 眉毛是不是"淡短斜线" / 眼睛是不是黑豆
  - **禁填充用正向写法** —— `Do NOT fill...` 实测失效, 头发会变实心黑块或太浅像白发
- 6-9 月的 IP 形象图 prompt 含 "short-sleeve t-shirt" + "Hangzhou summer"

### 4. 敏感词检查: `xiaofan-ink/tools/sensitive-check.py`

- 4 类检查: 品牌名 (珠宝/餐饮/酒水) / 违规引导 (扫码/加微信) / 医疗夸大 / 金融夸大
- 集成到 `articles-to-wechat.py` 步骤 1.5
- 默认 warn-only 不阻断, 加 `--strict` 阻断

### 5. 同步草稿: `xiaofan-ink/tools/articles-to-wechat.py`

```bash
# 同步 1 篇
python xiaofan-ink/tools/articles-to-wechat.py 017

# 列所有 essays
python xiaofan-ink/tools/articles-to-wechat.py --list

# 测试 API
python xiaofan-ink/tools/articles-to-wechat.py --test
```

**输出**:
- 配图 5 张上传到图文消息内图片 API
- 封面用 `00-*.png` 作 `thumb_media_id`
- 草稿创建成功 → 草稿 ID
- 草稿 ID 记到 `doc/SERIES-DRAFT-IDS.md`

### 6. 草稿箱清理 (用户手动, 微信 API 不支持删)

- 多次同步会留多版本, 用户去公众号后台草稿箱手动删
- `doc/SERIES-DRAFT-IDS.md` 草稿箱段只保留最新 ID

### 7. 群发 (用户手动)

- 公众号后台草稿箱 → 选草稿 → 群发/定时发布
- 群发后草稿 ID 失效, `doc/SERIES-DRAFT-IDS.md` 已发段不保留 ID
