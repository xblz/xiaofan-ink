## 抖音创作硬规则 (待写入 style-guide §7)

1. **文案 ≤ 300 字** (抖音图文限制)
2. **1 句扎心结尾** (引用块), 不喊口号
3. **引用心理学概念** (认知行为/依恋类型/防御机制/原生家庭) 但不学术化
4. **1-9 张 1:1 图** (默认) 或 3:4, 配图规则延续 v1.8 (动作型→IP, 状态型→去 IP)
5. **封面 1:1 必须** (待拍板: 1:1 vs 3:4)
6. **不主动亮心理咨询师证书**, 让内容自己说话
7. **不重复公众号主题** — 同一时段, 两个平台写不同切口
8. **同步节奏**: 想写就写, 不立 flag, 不催更 (跟 v2.0 节奏一致)
