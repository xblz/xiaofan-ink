## 抖音图文视觉规范 v2.8.7 (8/25 风格再校准, 用户拍板)

> **跟 fork 之前 Ian 风格对齐 + warm-ink 4 色调色板** (用户 8/25 指令: "看下 fork 项目之前的内容风格, 不要修改 IP 人物风格, 优化素材" + "配色是我们自己的, 不必每张都出现 IP")

### 视觉铁律 (v2.8.7)

1. **纯白底** — 无任何"撕下边/米色草稿纸/锯齿边/装订孔/阴影/渐变" 装饰, **全砍**
2. **warm-ink 4 色都用**:
   - 墨 #1A1A1A — 主体线稿/小凡
   - 红 #C0392B — 重点批注/问题/结果 (brush 圈重点字/数字)
   - 橙 #E67E22 — 路径/箭头/动作/动态
   - 蓝 #2C5F8D — 补充说明/系统状态
3. **图解型构图**: 1 个核心动作/物体 + 周围手写批注 + 红色高亮 + 蓝色注解 + 橙色路径/箭头
4. **大量留白** — 主体只占 40-60%, 留白是设计的一部分
5. **每张配图承载 1 段完整文案** (1-2 句, 跟公众号 020/021 配图同源)
6. **红色 brush stroke 圈重点字/数字** (不是装饰飘着)
7. **不每张都画 IP**:
   - "你" 的第一人称视角 → 只画手/手指/通用小人 (stick figure)
   - 抽象"你" 的状态 → 通用小人 (stick figure)
   - 具体动作主体 (秒回/看屏幕/坐工位) → 用小凡 IP

### 跟 fork 上游 Ian 风格一致 (6865757 README 视觉铁律)

- 纯白背景, 不要纸纹/米色/阴影/渐变
- 黑色手绘线稿, 细线, 轻微抖动
- 大量留白, 主体只占画面约 40%-60%
- 少量红色、橙色、蓝色中文手写批注
- 一张图只表达一个核心动作、结构、状态或隐喻
- 详细手绘物件 (信息井/鱼开膛/压机/发酵罐/吊桥 — "装置 + 批注" 风格)
- 我们 IP (小凡) **不修改** (保留 `xiaofan-ink/assets/ip-reference/standard.png` 那张"线稿版的我")

## 抖音创作硬规则 (沉淀到 style-guide §10)

1. **文案 ≤ 300 字** (抖音图文限制)
2. **1 句扎心结尾** (引用块), 不喊口号
3. **4 件套结构** (v2.8.6 起, 003 跑赢的真正原因):
   - 数字 + 重复节奏 (像 rap)
   - "你以为 X, 其实是 Y" 强反转
   - 强私密代入 ("我做过") 而非公共旁观
   - 强钩子 (让人想展开文案)
4. **不重复公众号主题** — 同一时段, 两个平台写不同切口
5. **不主动亮心理咨询师证书**, 让内容自己说话
6. **不写鸡汤/治愈系/积极向上** (跟 IP 调性冲突)
7. **不用 emoji** (死板冷静, 跟公众号 §8 一致)
8. **同步节奏**: 想写就写, 不立 flag, 不催更 (跟 v1.7 节奏一致)
9. **不每张图都画 IP** (v2.8.7): 根据场景决定 (手/手指/通用小人 vs 小凡)

  - 反向社交

**正文 (≤ 300 字)** + **抖音上传指南** 段 + **配图说明** 段 (v2.8.7 风格说明) + **插画元素** 列表

### 2. 配图生成: `image_synthesize` 工具

- **v2.8.7 视觉铁律**: 纯白底 + 4 色调色板 + 图解型 + 大量留白
- **IP 形象图**: `xiaofan-ink/assets/ip-reference/standard.png` 作 `input_file_paths` (酌情, 不每张)
- **PIL JPEG 化**: 抖音上传兼容性, ffd8 JPEG 数据 + .png 后缀 (跟公众号一致)

### 3. 配图规则 (跟公众号解耦, v2.8.7 修正)

- **图片比例**: 1:1 (1080x1080), 默认
- **张数**: **不固定, 由主题决定** (1-3 / 4-6 / 7-9 灵活)
- **风格**: 纯白底 + 4 色 + 图解型 + 大量留白 (v2.8.7)
- **每张配图配 1 个心理学插画元素** (v2.7.2 起): 天平/账本/箭头/对话气泡/小剪影/问号/折线图/分类柜/朋友圈网格
- **插画元素不重复** (v2.8.2 起): 查 `doc/douyin/README.md` 元素池, 不重复

### 4. 同步前自检 (v2.6.1 起, 抖音图文配图手动上传, 略)

- img 引用数 (`![]()` 数量) = front matter `images:` 列表数 (公众号硬规则, 抖音图文手动上传不强制, 但保持习惯)
