## 内容定位 (跟公众号完全不同)

| 维度 | 公众号 (小凡的草稿本) | 抖音 (观心微语) |
|---|---|---|
| 主题 | 工具反思 / 过程 > 结论 | 心理学 / 情感 / 扎心文案 |
| 调性 | 死板冷静 / 不卖萌 | 死板冷静 / 不卖萌 (同源) |
| 视觉 | 白底小凡 deadpan 草图 | 治愈光感 / 心率 + 海浪 + 月亮 (抖音独立) |
| 文案长度 | 1000-1500 字 | 300 字以内 |
| 配图比例 | 16:9, 4 张 | 1:1 或 3:4, 1-9 张 |
| 封面 | 订阅号用不上 | 1:1 必须, 抓眼 |
| 风格统一项 | 调色板 / 字体 / 留白 / 不喊口号 / 不卖萌 | 同上 |

**核心约束**:
- 公众号写"工具反思", 抖音写"心理学", 两个独立, 主题不交叉
- IP 形象 (小凡) 共享 reference 库, 但具体配图场景走各自调性
- 文案调性共享"不卖萌/不喊口号", 但落点不同 (公众号 = 工具, 抖音 = 心理)

## 抖音创作硬规则 (待写入 style-guide §7)

1. **文案 ≤ 300 字** (抖音图文限制)
2. **1 句扎心结尾** (引用块), 不喊口号
3. **引用心理学概念** (认知行为/依恋类型/防御机制/原生家庭) 但不学术化
4. **1-9 张 1:1 图** (默认) 或 3:4, 配图规则延续 v1.8 (动作型→IP, 状态型→去 IP)
5. **封面 1:1 必须** (待拍板: 1:1 vs 3:4)
6. **不主动亮心理咨询师证书**, 让内容自己说话
7. **不重复公众号主题** — 同一时段, 两个平台写不同切口
8. **同步节奏**: 想写就写, 不立 flag, 不催更 (跟 v2.0 节奏一致)

## 视觉风格决策 (待拍板)

**已观察**:
- 抖音头像: 心率波形 + 站立的金色人形剪影 (深蓝/黑底, 心理学调)
- 抖音背景图: 月亮 + 星光 + 海浪 (蓝色调, 治愈调)
- 跟公众号 `brand/avatar.png` (白底小凡草图) 风格完全不同

**问题**: 之前说"IP 和绘图风格保持统一", 实际:
- IP 形象 (小凡 deadpan 脸) 可以共享 reference
- 抖音配图场景 (治愈/光感) 跟公众号 (草图/白底) 是不同调

**3 个方案**:
- **A. 抖音配图也用小凡 IP**: 但背景走治愈调, 跟抖音头像/背景图呼应
- **B. 抖音配图用治愈系场景** (海浪/星空/单人剪影), 不画小凡 IP
- **C. 混合**: 1-2 张 IP 形象图 (动作型) + 1-2 张治愈场景图 (状态型), 跟 v1.8 配图规则一致
