# 构图模式与原创规则

## 基础结构类型

选择一种结构即可，不要混太多。

### Workflow 流程

适合：输入 -> 处理 -> 输出，内容生产，AI 工作流，自动化链路。

画法：左侧输入，中间小凡或怪机器处理，右侧输出，橙色箭头表达主流向。

### 系统局部

适合：信息来源、过滤器、数据库、渲染器、agent 系统局部。

画法：只画 3-5 个核心模块，小凡参与其中一个关键动作。

### 前后对比

适合：混乱/有序，手动/自动，分散/收拢，焦虑/稳定。

画法：左混乱，右稳定，中间橙色箭头。角色可以更夸张。

### 角色状态

适合：用户痛点、创作者状态、工具太多、信息焦虑、卡住到跑起来。

画法：2-4 个小状态，每个状态一个短标注。

### 概念隐喻

适合：内容工厂、信息仓库、脑内黑盒、工作流机器、自动日报。

画法：一个大的怪物件或机器，少量输入，一个输出。要有记忆点。

### 方法分层

适合：方法论框架、系统层级、能力栈、内容系统分层。

画法：一层层盒子，不要正式金字塔；小凡在旁边搬砖或搭建。

### 地图路线

适合：从想法到上线、用户路径、内容承接路径、学习路线。

画法：一条弯曲路径，少量节点，小凡牵线或走路。

### 小漫画分镜

适合：失败到成功、真实过程、吐槽、使用前后变化。

画法：2-4 个小场景，每格只表达一个动作。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图。

### 三步

1. 把抽象概念换成一个物理动作：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流。
2. 把系统结构换成一个低科技物件：坏掉的机器、纸箱、抽屉、水管、邮筒、怪表盘、秤、井、梯子、奇怪工位。
3. 让小凡承担动作：不是站旁边，而是卡在机器里、拉错线、守门、搬运、修补、称重、扶梯子、记录、把东西塞进某个怪装置。

### 可用物件池

- 纸箱、抽屉、旧机器、漏斗、秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪工位。
- 用时只选 1-2 个，不要堆满。

### 小凡动作池

- 拉、扛、塞、捞、压、称、缝、剪、拧、守、推、接、拆、标记、回收。
- 动作要服务核心意思，不要为了怪而怪。

## 反复刻规则

不要默认打开或复刻 `assets/ip-reference/`。定稿参考图只用于风格校准（线条密度、留白比例、姿态松散度、小凡气质），不能直接复用构图。

一旦某个构图用过一次，同一篇文章内不要再用第二次。同一篇文章里多张图的小凡，姿态、动作、物件、视角至少要有 3 个不同维度在变化，不能只换标注词就交差。

以下是"小凡反复刻高风险动作"，生成时主动回避或换新隐喻：

- 卡在机器里拉线 / 操作杆
- 双手拉绳子汇聚信息源
- 变漏斗分拣
- 切开素材类比（切鱼 / 切面包 / 切纸）
- 牵线走路（承接路径）
- 举牌看坑
- 盖章话术
- 托下巴思考（头部特写）
- 从纸箱探出半身
- 探出机器看画外

同类主题也要换新隐喻。例如"承接路径"不一定画路线，可以画小凡把内容尾巴接到门把手；"分拣漏斗"不一定画漏斗，可以画小凡从一堆纸里挑出几张；"切素材"不一定切鱼，可以切纸团、压面团、撕信封。

如果一篇文章有 4-8 张图，姿态/物件/视角至少有 3 个维度在变化，而不是换标注词就交差。

## 实战反复刻陷阱（2026-07-16 复盘）

第一篇实战文章 `doc/whiteboard-vs-doc.md` 的 4 张图(白板比文档更值钱)生成后复盘,发现两个反复刻陷阱,补在这段提醒:

### 陷阱 1:姿态都偏"站"

实战 4 张图小凡主姿态是"站着看 / 站着做",只覆盖 1.5 个维度(站+看/做)。原 IP 描述里强调的"做事中被打断"(蹲 / 卡住 / 探出 / 被绊住) 都没用上。

**避免方法**:

- 列 shot list 时,先在纸上标出每张图小凡的"姿态关键词"(站/蹲/卡住/探出/低头/回头/托下巴/被绊)
- 同一篇文章的 4-8 张图,姿态关键词至少 4 种不同
- 标"站"的不超过总图数的 50%

### 陷阱 2:物件都偏"低科技机器"

实战 4 张图都用了"低科技物理隐喻"(被擦掉的文档 / 白板 / 压面机 / 天平),6 张 skill 样例图也 5 张用了"低科技机器"(传送带 / 漏斗 / 压面机 / 发酵罐 / 桥)。"机器"是反复刻高风险物件。

**避免方法**:

- 物件池不限于机器,可扩展:纸箱 / 门 / 路 / 瓶子 / 船 / 桌子 / 椅子 / 书架 / 邮筒 / 梯子 / 锁 / 钥匙 / 绳子
- 同一篇文章的 4-8 张图,物件至少 3 种不同(不能每张都是"机器")
- 物件重复时,强制改变小凡与物件的"互动方式"(看 / 操作 / 卡住 / 推 / 拉 / 探 / 躲)
