## ⛔ IP 形态必过项 (含 IP 的图, 先查这 6 条)

**任何一条不过就重画。** 整图看容易漏, **必须裁切放大看脸**。

- [ ] **刘海在不在?** 额头上有没有一撮撮**尖角碎发垂到眉骨**? 后梳 / 大背头 / 露额头 = **直接重画**
- [ ] **眉毛是不是"淡短斜线"?** 应该是"很淡的短斜线, 比头发浅很多"。
      **一道眉毛都没有也算不过** —— 那是另一个方向的偏差
- [ ] **眼睛是"细长弧线 + 内眼角一个小黑点"?** 还是画成了**两个黑豆 / 有眼白的动漫眼**?
- [ ] **脸型偏长椭圆?** 下颌线干净, 下巴不方不圆, 不是圆脸
- [ ] **手有指节, 手指是分开的?** 不是圆润卡通手, 不是三笔占位
- [ ] **头发是"黑"的, 但不是实心黑块?** 应该是密集笔触 + 可见白缝;
      实心黑块 = 填充过度, 灰白发 = 填充不足

### 裁切放大怎么切

```python
im.crop((脸左上x, 脸左上y, 脸右下x, 脸右下y)).resize((840, 760)).save('/tmp/face.png')
```

> **整图验收 100% 漏眉毛** —— 这是实测结论, 必须放大。
> 1:1 缩略图下"动漫眼"和"细弧+点"几乎分辨不出。

## 必过项

- 是 16:9 横版 (公众号) 或 1:1 (抖音)。
- 背景是干净白底。
- 有小凡。
- 小凡承担核心动作,不只是装饰。
- 没有复刻旧案例构图,而是为当前文章生成了新隐喻。
- 画面怪诞、有创意、有意思。
- **公众号**: 主体占画面 50%-65%,**人物和场景不可分割**。
  判据: **删掉人物后图还成立 = 空壳 = 重画**。
- **抖音**: 主体占 40-60%,大量留白。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读。
- 橙色只用于主路径或箭头。
- 红色只用于重点、问题、提醒或结果。
- 蓝色只用于补充说明、反馈或系统状态。
- **没有我没要求的文字 / 箭头 / 圈注** (包括物体上"看起来该有"的标签)。
- **没有实心填充** (头发、衣服、物件) —— 用密集笔触表现黑度, 不是色块。
- **线条是松的**: 有飞白、有不闭合, 不是干净矢量线, 不是商业线稿插画。
- **信息图解型**: 每条连接线都完整画出来了, 且真的接到两边的框上。

具体配色值(温暖墨水感)见 `style-dna.md` 调色板:黑 `#1A1A1A` / 红 `#C0392B` / 橙 `#E67E22` / 蓝 `#2C5F8D`。

## 失败信号

出现以下情况,重生成或局部编辑:

### IP 形象类 (v2.8.43 新增)

- **头发后梳 / 大背头 / 额头全露** —— IP 最核心的识别特征没了。
- 眉毛完全消失, 或画成两道粗黑眉。
- 眼睛是黑豆 / 有眼白 / 有瞳孔 / 带高光。
- 脸偏圆, 或下巴偏方。
- 头发是实心黑块, 或灰白发。
- 手是圆润卡通手, 或三笔占位。

### 其他

- 左上角有"常见坑 / Workflow / 系统架构图 / 路线图"等标题。
- 小凡像吉祥物、表情包或可爱卡通。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多。
- 文字变成大段解释。
- **出现了我没要求的文字 / 箭头 / 圈注** (含物体上的价签、招牌、界面文字)。
- 背景有纸纹、阴影、渐变、米色、噪点。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板,没有荒诞隐喻。
- 线条太干净太矢量,像商业插画而不是白板草图。
- 和 `assets/ip-reference/` 里的定稿参考图过于相似,或近期用过的构图重复。

## 迭代方法

### IP 形象失真怎么修 (v2.8.43)

- **刘海没了 / 后梳了** → 不是加禁令能修的。**要正向写死刘海**:
  `A spiky pointed fringe falls across the forehead, strands hanging down to just above the eyebrows. The fringe MUST be visible on the forehead. NOT slicked back, NOT combed back, NOT brushed back.`
- **粗黑眉** → 不要禁到"一根都没有"。改成正向的淡短斜线:
  `EYEBROWS - extremely faint, thin, short slanted strokes, much lighter than the hair.`
- **黑豆眼 / 动漫眼** → 给正向形态 + 只禁结构性词:
  `narrow slit-like eyes … ONE thin elongated line with ONE tiny solid black dot at the INNER corner. NO white of the eye, NO eyeball, NO round pupil.`
- **头发实心黑块** → 抽象禁令不管用, 换正向:
  `Hair is drawn with a few loose sketchy strokes that let the white paper show through the strands, never a solid black shape.`
- **头发太浅像白发** → 补 `HAIR DENSITY`: `many separate overlapping black strokes … reads clearly DARK like black hair, while individual strand lines and small white gaps stay visible.`
- **局部只改脸** → 用 `prompt-template.md` 的「修 IP 形象」编辑提示, 别整张重画。

> ⛔ **每次加禁令前先问: 这条禁令会不会连带干掉别的东西?**
> v2.8.42 事故就是「禁眉毛 → 逼出后梳 → 抹掉刘海」。

### 其他迭代

- 太普通:让小凡成为动作主体,加入一个奇怪但成立的隐喻。
- 太复杂:删节点,只保留一个动作和 3-5 个短标注。
- 太可爱:强调 deadpan、blank serious expression、not cute、not mascot。
- 太 PPT:去掉标题、边框、整齐网格和过多箭头,改成手绘场景。
- 太像旧案例:保留核心意思,换掉主物件和小凡动作。
- 文字错:优先局部编辑;错得多就重生成并减少标注数量。
- 多了没要求的文字/箭头:先查**风格段**是不是在教它画批注 (v2.8.39 根因), 再看单图约束。

## 交付判断

高质量图应该让读者先觉得"有点怪",然后 1 秒内看懂结构。

如果第一眼像教程页,而不是白纸上的怪诞产品草图,就不合格。

**含 IP 的图再加一条**: 读者应该一眼认出"这是小凡",而不是"这是某个动漫角色"。
