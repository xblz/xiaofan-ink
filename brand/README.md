## §1 头像

`avatar.png`,1:1 比例,纯白底,撕下草稿纸角 + 几笔小凡速写 + 一抹红/橙强调色。

- **核心元素**:撕下的草稿纸(不规则撕痕)+ 小凡侧脸速写 + 1 抹暖色 highlight
- **为什么是草稿纸角**:跟"草稿本"号名直接呼应,跟系列"过程比结论值钱"调性契合
- **设计细节**:白底线稿 + 一抹橙/红强调(耳后/刘海附近),在小尺寸(64x64)下也清晰
- **小尺寸优化**:主元素不挤压,留白充足,圆角裁切后不丢失信息

> 头像生成由 xiaofan-ink skill 完成(用 `image_synthesize` 工具,标准 IP prompt + 草稿纸角 prompt)。

## §2 欢迎语

详见 [`welcome.md`](welcome.md)。

**核心**:
- 欢迎来到小凡的草稿本。
- 这里每周三写一篇工具反思、节奏、专注相关的草稿。
- 写完就停,被打断也行,过程比结论值钱。
- 回复"目录"看历史文章。
- 回复"草稿"看最近的草稿碎片。

## §3 菜单

详见 [`menu.md`](menu.md)。

## §4 视觉规范

详见 [`style-guide.md`](style-guide.md)。

**核心**:
- 头图设计:16:9 撕下的草稿纸 + 几笔
- 封面设计:跟头图一致,字号清晰
- 排版:左对齐 / 段落短 / 中文标点用全角
- 颜色:温暖墨水感 4 色(跟 xiaofan-ink skill 调色板一致)
- 字体:中文用思源宋体或楷体(手写感)
- 引用块:暖灰底
- 代码块:无(本号不写技术细节)
