# 视觉规范

> 公众号"小凡的草稿本"的视觉规范,所有排版、配色、字体、封面、头图都遵循本文。
> 跟 xiaofan-ink skill 调色板一致(`xiaofan-ink/references/style-dna.md`)。

## 1. 调色板(温暖墨水感)

| 概念 | HEX | RGB | 用途 |
|------|-----|-----|------|
| 黑色 (ink) | `#1A1A1A` | (26, 26, 26) | 主体文字 / 线稿 / 标题 / 强调 |
| 红色 (alert) | `#C0392B` | (192, 57, 43) | 重要提醒 / 引用 / 警示 |
| 橙色 (path) | `#E67E22` | (230, 126, 34) | 行动 / 关键判断 / 链接 hover |
| 蓝色 (note) | `#2C5F8D` | (44, 95, 141) | 补充说明 / 二级标题 / 冷知识 |
| 米色 (paper) | `#F4EFE6` | (244, 239, 230) | 引用块底色 / 草稿纸感(可选) |
| 暖灰 (text-secondary) | `#666666` | (102, 102, 102) | 辅助文字 / 时间戳 |

**纪律**:
- 一篇推送**只突出 1 种标注色**(黑/红/橙/蓝),其他文字全部用黑
- 重要引用用红色高亮
- 行动号召用橙色
- 冷知识/补充用蓝色

## 2. 字体

| 场景 | 中文字体 | 英文字体 | 大小 |
|------|----------|----------|------|
| 标题 | 思源宋体 Heavy / 楷体 | - | 22-26 px |
| 副标题 | 思源宋体 Regular | - | 18-20 px |
| 正文 | 思源宋体 Regular | - | 16-17 px |
| 引用块 | 思源宋体 Light / 楷体 | - | 15-16 px |
| 标注 | 楷体 / 手写感 | - | 14-15 px |
| 英文混排 | - | Lora / EB Garamond | 同上 |

**为什么思源宋体 / 楷体**:
- 思源宋体:免费开源,可商用,有"手写感"和"传统"气质
- 楷体:更手写,适合引用和小标注
- **不**用思源黑体:太现代、太"互联网风",跟"草稿本"调性不符

## 3. 排版规则

### 3.1 段落

- 段落**短**(2-4 行为佳,绝不超 5 行)
- 段落间空 1 行
- 中文标点用**全角**(`,。?!";:()「」`)
- 数字和英文前后空 1 个半角空格(`小凡 写了 5 篇`)
- 引号统一用 `「」`(中文标准),**不**用 `"` 或 `""`

### 3.2 标题

- 一级标题:中文 24-26 px,加粗,**不**居中
- 段落小标题(段内):中文 18-20 px,可加粗或加引号
- 永远**不**用 ALL CAPS 英文大标题

### 3.3 强调

- 重要句子:**加粗**或**用红色**(不同时用)
- 关键判断:用 `>` 引用块(米色底)
- 不**用 emoji 强调**(死板冷静调性)

### 3.4 引用块

```
> 引用内容用米色底(#F4EFE6),左边有一道竖线
> 多行引用用同样的样式
```

适合:作者自己的核心判断、引用他人、列出"小凡说" 类的话

### 3.5 配图排版

- 每张图下方**不加** "图 1: xxx" 之类说明
- 配图之间空 1-2 行
- 配图宽度跟正文一致(不要全宽,留 5% 边距)
- 配图不加圆角阴影(白底/草稿感)

## 4. 封面(每篇推送的封面图)

- 尺寸:**2.35:1**(900x383 像素)或 **1:1**(200x200 像素)
- 设计要素:跟文章主题相关的小凡图 + 简短文字
- 风格:跟 `doc/essays/images/00X-*/` 配图一致(白底手绘)
- 文字:如果有,只放文章标题或一句话,不放其他

## 6. 写作姿态(v2.3 重写, 整章重塑)

**目标**: 写得像朋友发微信, 不像 AI 输出。

**核心**: 每篇可长可短、可断可连、可严肃可松散。**没有固定模板**。

之前定的"开头 + 3-5 段 + 收尾 + 引用块" 模板本身就是 AI 特征 — 整齐、对称、规整。读者一看就知道"这是 AI 写的"。

### 6.1 口水化(v2.3 新增)

像说话, 不像写作。

- **段长不均**: 有的段 1 行, 有的段 5-6 行, 同一篇里也要混着
- **句长不均**: 有的句 5 字, 有的句 30 字
- **段首不统一**: 不都用"我"开头, 不都用时间开头, 偶尔用反问 / 引用 / 感叹 / 直接事物开头
- **留语气词**: 嗯、嘛、吧、啊、呢、其实、说白了、老实说、说真的
- **故意不修**: 偶尔保留"卡"的地方(像真草稿,不像润色稿)
- **偶尔跑题**: 写着写着想起别的, 然后回来(真朋友发微信会这样)
- **不每段都论证**: 有的段是闲笔, 有的段是空气, 有的段就一句话

**对比**:
- ❌ AI 风: "我打开外卖 app, 5 分钟下单。"(SVO 工整, 节奏规整)
- ✅ 口水: "昨晚, app 一开, 5 分钟单下了。15 分钟, 饭到。"(短, 节奏碎, 像事后回忆)

### 6.2 排版不固定(v2.3 新增, v2.5 调整)

**核心**: 排版由主题决定, 不由"格式模板"决定。

- **段长随机**: 这篇可以是 1-2 行短段, 下篇可以是 5-6 行长段
- **配图张数随机**(v2.5 明确): 这篇 3 张, 下篇 1 张, 再下篇 5 张, 也可能 0 张纯文字
  - **根据主题决定**: 主题复杂 / 需要多角度呈现 → 多图; 主题简单 / 单一场景 → 少图
  - **不为"显得丰满" 加图**, 也不为"极简主义" 砍图
  - **最低 0 张, 最高不限**(但单篇建议 ≤ 6 张, 多于 6 张读者疲劳)
- **配图位置随机**: 不都在段首, 偶尔段中, 偶尔段尾, 偶尔两段之间放图
- **## 标题用不用随机**(v2.5 调整): 之前说"不用 H2" 走极端了, 实际是 — 主题需要分段就用, 不需要就不用
  - 视觉骨架像之前(007/008) 4 张图 + ## 分割也是 OK 的
  - 但 ## 之间内容长度要**不均**(短 1-2 行 / 中 3-4 行 / 长 5-6 行混), 不能像 007/008 那样每段均匀
- **引用块用法随机**: 偶尔 1 个, 偶尔 3 个, 偶尔没有
- **不用列表**: 不用 bullet 列表, 不用有序列表(列表是 AI 偏爱)
- **不用 emoji 强调**

**最高规则**: 如果两篇连起来看着像同一个模板生成的, 就失败了。

**v2.5 反思**: v2.3 说"不用 H2" 走极端, 配图 1 张也走极端。 实际"自然松散" = 排版服务主题, 不是排版反抗规则。

### 6.3 主题词不喊出来(v2.2 沿用)

**核心三句话**(过程 > 结论 / 草稿 > 作品 / 死板冷静)是**账号**的调性, 不是**每篇文章**的口号。

读者关注时已经看过这三条, 看单篇文章时不需要再被教育一遍。

#### ❌ 反例(007/008 都中招)

- **标题里直接出现"草稿" / "过程"**: `AI 味儿被识别, 是因为跳过了草稿` — 标题就亮牌
- **文中反复提到主题词**: 每段提一次"过程", 加粗强调
- **收尾用"X 不重要, Y 重要" 显式归纳**: 收尾 3 句 `饭不重要, 做饭重要 / 切菜不重要, 切到手重要` — 这是 PPT 收束
- **引用块放主题句**: `> 草稿 > 作品。这句话, 不是我说的, 是我自己写出来的。` — 把主题塞进引用块, 像贴标语

#### ✅ 正例

- 标题点**具体现象**, 主题藏在文章里
- 主题词自然出现 0-2 次, 不加粗
- 收尾不归纳, 留白或冷幽默(比如"反正下次我还是会叫外卖")
- 引用块放具体例子 / 反问 / 留白

### 6.4 反 AI 自查清单(v2.3 新增)

写完一篇, 必查这 5 条:

1. **加粗次数** — AI 喜欢加粗强调, 真人很少。整篇加粗 ≤ 2 处, 还得是引用或专有名词
2. **"X 不重要, Y 重要"** — 显式归纳句, 删
3. **3 段 rule of three** — AI 喜欢凑三个。允许巧合的 3, 禁止刻意的 3
4. **转折词密度** — "然而 / 此外 / 更进一步 / 不仅如此" — 删
5. **段首重复** — 连续 3 段以上都以"我"开头, 改

更彻底的: 通篇读一遍, 问自己"如果这是朋友发我的微信, 我会怎么回?" 如果回"哦"或"嗯嗯", 说明写得太 AI, 改。

### 6.5 检验标准(合并)

写完一篇, 通读一遍, 自问:
1. 标题有没有直接出现"草稿" / "过程" / "死板"?
2. 正文中"草稿" / "过程" / "死板" 出现了几次? 加粗了没?
3. 收尾有没有用"X 不重要, Y 重要" 模式?
4. 引用块是不是只放了"主题归纳"?
5. 加粗总数超过 2 了吗?
6. 连续 3 段以上段首重复了吗?
7. 转折词用了几个?
8. 这篇跟上一篇的"骨架" 长得像不像?

任何一条是, 重写。

**最终目标**: 写"过程 / 草稿"主题的文章, 本身要像一篇**草稿**, 不像一篇**完成品 + 口号**。

## 8. 不做的事

- ❌ 不在推送里加"扫码关注"、"点击在看" 类大图(微信公众号原生功能足够)
- ❌ 不放二维码图(只在简介里放)
- ❌ 不每篇都加"打赏"按钮(本号不是变现号)
- ❌ 不做广告合作(目前没考虑)
- ❌ 不用 emoji(死板冷静调性)
- ❌ 不用"看完点赞" / "支持原创" 类陈词滥调

## 9. 跨平台一致性

公众号、小红书、知乎、Newsletter 等平台,**视觉规范统一**:
- 调色板一致
- 字体一致(思源宋体 / 楷体)
- 排版规则一致
- 配图风格一致

不同平台可以**改**内容顺序,但**不**改视觉。
