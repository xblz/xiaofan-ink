# 视觉规范

> 公众号"小凡的草稿本"的视觉规范,所有排版、配色、字体、封面、头图都遵循本文。
> 跟 xiaofan-ink skill 调色板一致(`xiaofan-ink/references/style-dna.md`)。

## 1. 调色板(温暖墨水感)

| 概念 | HEX | RGB | 用途 |
|------|-----|-----|------|
| 黑色 (ink) | `#1A1A1A` | (26, 26, 26) | 主体文字 / 线稿 / 标题 / 强调 |
| 红色 (alert) | `#C0392B` | (192, 57, 43) | 重要提醒 / 引用 / 警示 |
| 橙色 (path) | `#E67E22` | (230, 126, 34) | 行动 / 关键判断 / 链接 hover |
| 蓝色 (note) | `#2C5F8D` | (44, 95, 141) | 补充说明 / 二级标题 / 冷知识 |
| 米色 (paper) | `#F4EFE6` | (244, 239, 230) | 引用块底色 / 草稿纸感(可选) |
| 暖灰 (text-secondary) | `#666666` | (102, 102, 102) | 辅助文字 / 时间戳 |

**纪律**:
- 一篇推送**只突出 1 种标注色**(黑/红/橙/蓝),其他文字全部用黑
- 重要引用用红色高亮
- 行动号召用橙色
- 冷知识/补充用蓝色

## 2. 字体

| 场景 | 中文字体 | 英文字体 | 大小 |
|------|----------|----------|------|
| 标题 | 思源宋体 Heavy / 楷体 | - | 22-26 px |
| 副标题 | 思源宋体 Regular | - | 18-20 px |
| 正文 | 思源宋体 Regular | - | 16-17 px |
| 引用块 | 思源宋体 Light / 楷体 | - | 15-16 px |
| 标注 | 楷体 / 手写感 | - | 14-15 px |
| 英文混排 | - | Lora / EB Garamond | 同上 |

**为什么思源宋体 / 楷体**:
- 思源宋体:免费开源,可商用,有"手写感"和"传统"气质
- 楷体:更手写,适合引用和小标注
- **不**用思源黑体:太现代、太"互联网风",跟"草稿本"调性不符

## 3. 排版规则

### 3.1 段落

- 段落**短**(2-4 行为佳,绝不超 5 行)
- 段落间空 1 行
- 中文标点用**全角**(`,。?!";:()「」`)
- 数字和英文前后空 1 个半角空格(`小凡 写了 5 篇`)
- 引号统一用 `「」`(中文标准),**不**用 `"` 或 `""`

### 3.2 标题

- 一级标题:中文 24-26 px,加粗,**不**居中
- 段落小标题(段内):中文 18-20 px,可加粗或加引号
- 永远**不**用 ALL CAPS 英文大标题

### 3.3 强调

- 重要句子:**加粗**或**用红色**(不同时用)
- 关键判断:用 `>` 引用块(米色底)
- 不**用 emoji 强调**(死板冷静调性)

### 3.4 引用块

```
> 引用内容用米色底(#F4EFE6),左边有一道竖线
> 多行引用用同样的样式
```

适合:作者自己的核心判断、引用他人、列出"小凡说" 类的话

### 3.5 配图排版

- 每张图下方**不加** "图 1: xxx" 之类说明
- 配图之间空 1-2 行
- 配图宽度跟正文一致(不要全宽,留 5% 边距)
- 配图不加圆角阴影(白底/草稿感)

## 4. 封面(每篇推送的封面图)

- 尺寸:**2.35:1**(900x383 像素)或 **1:1**(200x200 像素)
- 设计要素:跟文章主题相关的小凡图 + 简短文字
- 风格:跟 `doc/essays/images/00X-*/` 配图一致(白底手绘)
- 文字:如果有,只放文章标题或一句话,不放其他

## 6. 文章固定结构

每篇推送的开头和结尾固定:

### 6.1 开头

```
[标题]

[第一张配图,1-2 段引入]

[文章正文...]
```

### 6.2 结尾

```
---

> 写完这篇,[一句冷幽默/反共识/留个问号]

[最后一张配图,可选]

如果觉得有共鸣,点"在看"或转发一下,本号会因此被更多人看到。
下一篇什么时候,看心情。
```

### 6.3 主题词不喊出来 (v2.2 新增)

**核心三句话**(过程 > 结论 / 草稿 > 作品 / 死板冷静)是**账号**的调性, 不是**每篇文章**的口号。

读者关注时已经看过这三条, 看单篇文章时不需要再被教育一遍。

#### ❌ 反例 (007/008 都中招了)

- **标题里直接出现"草稿" / "过程"**: `AI 味儿被识别, 是因为跳过了草稿` — 标题就亮牌, 读者还没读就知道你要说啥
- **文中反复提到主题词**: 每段提一次"过程", 加粗强调
- **收尾用"X 不重要, Y 重要" 显式归纳**: 收尾 3 句 `饭不重要, 做饭重要 / 切菜不重要, 切到手重要 / 菜做得好不好不重要, 你愿不愿意试一次重要` — 这是 PPT 收束, 不是文章收束
- **引用块放主题句**: `> 草稿 > 作品。这句话, 不是我说的, 是我自己写出来的。` — 把主题塞进引用块, 像贴标语

#### ✅ 正例

- **标题不出现主题词**: 标题点出**具体现象**, 主题藏在文章里
- **正文中主题词自然出现 0-2 次**: 出现就出现, 不加粗, 不强调
- **收尾不归纳, 留白或冷幽默**: 比如"反正下次我还是会叫外卖"
- **引用块放具体例子 / 反问 / 留白**: 不用来总结中心思想

#### 检验标准

写完一篇, 通读一遍, 自问:
1. 标题有没有直接出现"草稿" / "过程" / "死板"?
2. 正文中"草稿" / "过程" / "死板" 出现了几次? 加粗了没?
3. 收尾有没有用"X 不重要, Y 重要" 模式?
4. 引用块是不是只放了"主题归纳"?

任何一条是, 重写。

**最高级的"过程 > 结论"**: 写"过程 > 结论"主题的文章, 本身要像一篇**草稿**, 不像一篇**完成品 + 口号**。

## 8. 不做的事

- ❌ 不在推送里加"扫码关注"、"点击在看" 类大图(微信公众号原生功能足够)
- ❌ 不放二维码图(只在简介里放)
- ❌ 不每篇都加"打赏"按钮(本号不是变现号)
- ❌ 不做广告合作(目前没考虑)
- ❌ 不用 emoji(死板冷静调性)
- ❌ 不用"看完点赞" / "支持原创" 类陈词滥调

## 9. 跨平台一致性

公众号、小红书、知乎、Newsletter 等平台,**视觉规范统一**:
- 调色板一致
- 字体一致(思源宋体 / 楷体)
- 排版规则一致
- 配图风格一致

不同平台可以**改**内容顺序,但**不**改视觉。
